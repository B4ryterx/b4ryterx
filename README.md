# Brandon-Jason Adebayo

AI undergraduate at **MBZUAI** (Abu Dhabi) and undergraduate researcher in Prof. Abdalla Swikir's robotics lab, working on **safe reinforcement learning with control barrier functions**: learning controllers that stay provably safe, with the safety condition built into training.

I apply the same idea to markets, and I try to report what didn't work as clearly as what did.
